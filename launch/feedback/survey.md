# 反馈问卷（3–5 分钟）

我们想知道你**真的在算什么**、**卡在哪一步**。所有问题都可跳过；愿意深聊的
可以留邮箱，我们约 20 分钟访谈。

请复制下面的问题，发到：

- GitHub issue：https://github.com/ai4energy/esml/issues/new?template=feedback.md
- 或邮件：mingtao.li@gmail.com（标题写“反馈”）

---

1. **你在建什么模型 / 算什么物性？**
   （例如：IEEE 300 潮流、区域供热网、水蒸汽状态点、甲烷-乙烷相包络、课程练习）

2. **你卡在哪一步？**
   - [ ] 下载/安装
   - [ ] 第一个模型
   - [ ] 第一条报错（请贴完整输出）
   - [ ] 文档/教程
   - [ ] 结果与预期不符（请给期望值/实际值）
   - [ ] 其他：______

3. **你现在用什么工具？为什么想换/想试？**
   （不用点名商业软件，说“脚本 + 某求解器”“课程给的模板”即可）

4. **你希望它下一步长成什么样？**
   （例如：Windows 版、更多流体、某个导入格式、闭环/MPC、更快的求解）

5. **愿意接受 20 分钟访谈吗？**（可选）
   邮箱/微信：______

## 我们的承诺

- **24 小时内首响**（工作日）。
- 安装、第一个模型、第一条报错这类“第一英里”问题按 **bug** 处理。
