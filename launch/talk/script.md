# 讲稿：ESML × MMPROPS（20 分钟）

> 原则：一页一个观点；数字都能复跑；主动说边界。不要念幻灯片。
> 时间含切换；Q&A 另算。备用页不占 20 分钟。

## 0:00–0:40 ｜ S1 标题

**说**：今天讲两个引擎。一个把能源系统的模型变成可解系统（ESML），
一个把物性变成可调用服务（MMPROPS）。一句话概括：**从分子到电网**。

**不要**：念“Ai4Energy · 20 分钟技术分享”。

## 0:40–2:00 ｜ S2 两道坎

**说**：做能源系统计算，绕不开两件事：

- 建模：手写 Newton、稀疏雅可比、初值、事件；每换一个模型重来一遍。
- 物性：状态点、饱和、闪蒸、相平衡；关联式、单位、收敛各一套。

**落点**：我们把这两件事分别收进两个引擎——一个管模型，一个管物性。

## 2:00–3:40 ｜ S3 编译链

**说**：ESML 不是“又一个求解器”。模型是声明式的：变量、参数、方程。
编译器做展平、指标约简、结构分析（BLT）、因果化/撕裂，最后才进牛顿或 BDF。

**强调**：结构、单位、因果在编译期检查；运行时只剩数值、事件、积分。

## 3:40–5:00 ｜ S4 一个模型

**说**：这是一个最小的衰减模型：一个参数、一个状态、一个方程。
模型是数据；求解器是编译器的一部分。

**不要**：逐行念 XML。指一下 `Der(x) = -lam * x` 即可。

## 5:00–6:20 ｜ S5 为什么不是脚本

**说**：用脚本也能解，但工程判断在结构、因果、事件：

- 结构分析决定哪些方程要一起解；
- 因果化/撕裂决定哪些能显式算、隐式块多大；
- 一致初值和事件定位决定 DAE 能不能稳定跑。

这些不是库函数，是编译链的一等公民。

## 6:20–8:50 ｜ S6 IEEE 300 实测

**说**：IEEE 300，4,604 个展平未知量；本机 release 整进程墙钟 0.32 秒；
XSD 校验 0 error。命令和输出都在屏幕上。

**主动说边界**：学术版 ≤16,384 未知量；IEEE 2869 / 1354 / 9241 需要商业版；
超限会在求解前响亮报错，不会静默降阶。学术版启动提示走 stderr，stdout 只有 JSON。

## 8:50–10:10 ｜ S7 客户端

**说**：Python 和 Julia 客户端都是 MIT，只通过公开 JSON 协议调用引擎，
不含引擎代码。`solve` / `simulate` 是一次性调用，不保留状态；装完即用。

**如果被问**：常驻会话（DTIL：session / predict / snapshot）是商业版能力。

## 10:10–11:50 ｜ S8 MMPROPS 能力

**说**：物性侧五个子命令：props（状态点）、sat（饱和）、flash（闪蒸）、
vle（二元泡/露点）、envelope（T-x-y 包络）。数值可带单位，输出 JSON/CSV/文本。

**落点**：不是“又一个物性库”，而是可机读、可集成、失败语义清楚的独立引擎。

## 11:50–14:10 ｜ S9 实测值

**说**：挑两三个数字：水在 300 K / 1 bar 的 rho=996.556338；373.15 K 的
psat=101417.996368；甲烷/乙烷 220 K、x1=0.5 的泡点 p=3993218.99、y1=0.847911。

**重点讲右栏**：两相无定义量返回 null 而不是 0；未收敛/超范围响亮失败；
坏数据包不退回内嵌基线；VLE 只支持二元。这是工程用户最在意的。

## 14:10–15:40 ｜ S10 工程判据

**说**：不是 demo。全量 2,890 个测试通过、0 失败；23/23 合入闸门；
仓库里 1,058 个 `.esml` 模型；29 个 crate。每个数字都有日志和复跑命令。

**不要**：展开讲闸门细节；一句“可复跑”即可。

## 15:40–16:40 ｜ S11 XSD

**说**：XML 模型不再靠“跑一遍看看”。canonical XSD 已挂到公网，
`xmllint` 一条命令校验；XSD 随语言规范 MIT；IEEE 300 用例 0 error。

**如果被问**：`canonical-basic` 需要同目录的 common/compute 两个 include；
页面上有完整命令。

## 预设问答

**Q：为什么不用 Python 直接写？**
A：脚本能解一个模型；难的是结构、因果、事件和一致的失败语义。这些放进编译链，
换模型不用重写求解器。

**Q：学术版和商业版差什么？**
A：学术版免费、≤16,384 未知量、只开放引擎核心；商业版无限制并含 DTIL。
客户端都是 MIT。

**Q：物性准不准？**
A：水/蒸汽走 IF97；二元混合物走 GERG。页面给了实测值和复跑命令；
未收敛/超范围会响亮失败，不会返回替代值。

**Q：有 Windows/macOS 吗？**
A：当前公开二进制是 Linux x86_64；客户端跨平台。Windows/macOS 在路线图上，
有真实需求会优先。

**Q：能用于课程吗？**
A：可以，学术/教学/个人非商业免费。欢迎把课程练习发给我们，我们帮你跑通。
